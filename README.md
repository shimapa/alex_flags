# Football scarves

Alex's collection of football scarves from clubs and national teams around the world, gathered since 2003:
browse every scarf, see them on a map, and read the statistics.

Open `index.html` locally (no build step), or visit the GitHub Pages site.

- `data/scarves.js` — the collection, generated by `tools/extract.py` from the original site
- `tools/fetch_badges.py` — matches club and federation badges on TheSportsDB
- Interface design adapted from [KolleK](https://github.com/djaiss/kollek) (MIT). See `CREDITS.md`.
