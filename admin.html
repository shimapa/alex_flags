Sign in with a GitHub token

The site lives in the GitHub repository shimapa/alex_flags. Adding a scarf saves the photo and its details there, and the site updates in a minute or two. You need a token that can write to that repository.

How to get a token
  1. Owner of the repository: open new fine-grained token. Repository access: Only select repositories, pick alex_flags. Permissions: Contents, Read and write. Generate and copy it.
  2. Collaborator (Alex): accept the invitation to the repository first, then create a classic token with only the public_repo scope.
